# JanAdhikar
This project is an AI-powered civic engagement and transparency platform designed to bridge the gap between citizens and local governance by integrating intelligent grievance redressal with public financial transparency into a single digital ecosystem. Citizens can report civic issues such as potholes, garbage accumulation, water supply failures, damaged roads, streetlight faults, and other public infrastructure problems through text, photographs, or GPS-tagged locations. Natural Language Processing (NLP) automatically analyzes each complaint, categorizes it based on issue type, determines its priority, and routes it to the appropriate government department for faster and more efficient resolution. Every complaint progresses through a transparent status pipeline—Filed, Assigned, In Progress, and Resolved—allowing citizens to monitor updates in real time while improving accountability and reducing the delays and lack of transparency commonly associated with traditional grievance systems. The platform also features a comprehensive public transparency dashboard that displays government project information, including project budgets, contractors, tenders, implementation timelines, and itemized expenditures, enabling citizens to access accurate and up-to-date financial records. An AI-powered anomaly detection module continuously analyzes these financial transactions to identify suspicious activities such as overspending, inflated invoices, duplicate bills, unusual expenditure patterns, or potential misuse of public funds, thereby strengthening financial accountability and promoting transparent governance. By combining AI-driven complaint management, real-time grievance tracking, and intelligent financial monitoring within a unified platform, the proposed system goes beyond conventional complaint applications and static information portals, empowering citizens not only to report civic issues efficiently but also to actively monitor government projects and ensure responsible utilization of public resources.
