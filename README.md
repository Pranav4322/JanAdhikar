# JanAdhikar
This project is an AI-powered civic engagement and transparency platform designed to bridge the gap between citizens and local governance. Citizens can report civic issues — potholes, garbage accumulation, water supply faults, and similar problems — through text, photos, or GPS-tagged locations, with Natural Language Processing automatically categorizing each complaint and routing it to the appropriate government department based on urgency and issue type. Every complaint moves through a transparent status pipeline — Filed, Assigned, In Progress, Resolved — giving citizens real-time visibility into how their concerns are being handled, which directly addresses the trust deficit created by opaque, delay-prone traditional grievance systems. Beyond complaint management, the platform features a public transparency dashboard that publishes government project details, including budgets, contractors, tenders, and itemized expenses, with an AI-driven anomaly detection layer that flags irregularities such as overspending, inflated bills, or duplicate receipts, adding a proactive layer of financial accountability rarely found in existing civic-tech solutions. By combining grievance redressal with financial transparency in a single system, the platform moves beyond typical single-purpose complaint apps or static information portals, offering citizens both a voice in reporting problems and a window into how public funds are actually being spent.
